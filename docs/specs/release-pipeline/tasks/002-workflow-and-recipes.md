# Task 002: Generate `release.yml` + CI plan job + just recipes

**Description:** Have cargo-dist generate `.github/workflows/
release.yml` from the Task-1 config, commit it, and add the guard
rails: a `dist-plan` job in `ci.yml` (fails PRs that break the
release plan) and the `dist-plan` / `dist-build` / `dist-lint` just
recipes plus `bootstrap` additions (cargo-dist, actionlint).

**Acceptance criteria:**
- [ ] `.github/workflows/release.yml` generated by cargo-dist (tag
      push `v*` trigger + `workflow_dispatch`), checked in, and
      `cargo dist plan` reports generated CI as up-to-date (no diff
      on regenerate)
- [ ] `ci.yml` gains a `dist-plan` job running `cargo dist plan`
      (with the xcap apt deps installed first — the plan reads
      Cargo.toml, so reuse `XCAP_LINUX_DEPS` if the tool needs them;
      drop the apt step if the plan succeeds without)
- [ ] justfile gains `dist-plan` (`cargo dist plan -q`), `dist-build`
      (host artifacts; on Linux/macOS also invokes the packaging
      scripts when they exist — guard for absence until Tasks 5/7),
      `dist-lint` (actionlint, graceful skip) — following the
      existing recipe conventions (shebang + `set -euo pipefail`,
      quiet-on-success)
- [ ] `bootstrap` installs `cargo-dist` (pinned 0.33.0) and
      `actionlint` idempotently
- [ ] release.yml defaults reviewed: no `--all-features` surprises,
      `GITHUB_TOKEN` permissions untouched

**Verification:**
- [ ] `just dist-plan` exit 0
- [ ] `cargo dist generate ci` (or `dist init --yes`) produces no
      diff after commit — regeneration is clean
- [ ] `just dist-lint` exit 0 (or graceful skip note)
- [ ] `actionlint` on both workflows if installed
- [ ] Push branch; `dist-plan` CI job green on the PR

**Dependencies:** Task 001

**Files likely touched:**
- `.github/workflows/release.yml` (new, generated)
- `.github/workflows/ci.yml`
- `justfile`

**Docs:**
- Boundary: release.yml is regenerated, never hand-edited. If a
  change is needed, change `dist.toml` and regenerate.

**Estimated scope:** Medium (3 files)
